# Deprecated: historical OpenSpec specs

These specs and change proposals describe the app as it was built between March and September 2026. They are kept for reference and are **no longer maintained**.

Several of them describe things that no longer exist: the Rust/WASM stroke-json runtime, publish-time compaction, the stroke-json lab and the Node adapter.

The current source of truth is [`docs/remaster/README.md`](../docs/remaster/README.md) (plan and decisions) together with the code and its tests.
